Sender authentication

Reads SPF, every DKIM signature and DMARC, and checks they line up with the From address.

Impersonation

Catches lookalike domains like paypa1.com, brand names in the display name and punycode tricks.

Origin server

Follows the Received chain to find the IP that really sent the email, and spots forged or delayed hops.

Links

Flags links whose text says one site but go to another, bare-IP links, shorteners and risky downloads.

Attachments

Hashes every file and spots double extensions, renamed executables and HTML smuggling, without opening anything.

Reputation, if you want it

With your API keys, looks up sender IPs on AbuseIPDB and attachment hashes on VirusTotal.

Mix IPs and hashes

Paste a list and each line is recognised as an IP, MD5, SHA-1 or SHA-256 on its own.

Defanged input works

Copy straight from a ticket. Values like 1[.]2[.]3[.]4 are cleaned up before the lookup.

IP abuse score

AbuseIPDB confidence score, number of reports and how many people filed them, and when it was last reported.

Who owns the IP

Country, ISP, domain and usage type, plus whether it is a Tor exit node or on AbuseIPDB's allow list.

Hash detections

How many VirusTotal engines call the file malicious or suspicious, its type, size and known file names.

File history

When the file was first and last submitted, how often, and a direct link to its VirusTotal page.

JavaScript

Finds scripts anywhere in the file, including ones hidden in object streams or behind escaped names.

Runs on open

Flags actions that fire by themselves when the PDF is opened, like OpenAction and document events.

Risky actions

Launching programs, opening links, sending form data out, and jumping to other documents.

Embedded files

Lists files hidden inside the PDF and calls out executables and scripts, even when they are renamed.

Obfuscation

Spots eval, unescape, character-code tricks, shellcode patterns and long hex strings inside scripts.

Fully offline

Nothing is sent anywhere and nothing is run. Extracted content goes into a password-protected zip.

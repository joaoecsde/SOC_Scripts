# Scripts_SOC

A collection of Python scripts built to help SOC analysts with day-to-day tasks — from threat intelligence lookups to automating repetitive investigative work.

The goal of this repo is to keep growing with practical, lightweight tools that speed up the analyst workflow without relying on heavy platforms or paid tooling.
